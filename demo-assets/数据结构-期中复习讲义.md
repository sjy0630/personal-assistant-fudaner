# 数据结构 期中复习讲义（第 1–6 章）

> 演示用虚构材料，内容为通用知识点整理，不对应任何真实课程讲义。

## 第 1 章 绪论

- 数据结构研究数据的**逻辑结构**、**存储结构**以及在其上定义的**运算**。
- 算法的五个特性：有穷性、确定性、可行性、输入、输出。
- 时间复杂度用大 O 表示法描述增长趋势：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ)。

## 第 2 章 线性表

- 顺序表：随机访问 O(1)；插入、删除平均移动 n/2 个元素，O(n)。
- 单链表：插入、删除只需修改指针，O(1)（已知前驱结点时）；按序号查找 O(n)。
- 双向链表：每个结点有 prior 和 next 两个指针，删除结点 p 时要同时修改 p->prior->next 和 p->next->prior。
- 头结点的作用：统一空表和非空表、首结点和其他结点的操作。

## 第 3 章 栈与队列

- 栈：后进先出（LIFO）。顺序栈判满条件 top == MaxSize - 1；链栈一般不会满。
- 应用：括号匹配、表达式求值（中缀转后缀）、函数调用与递归。
- 队列：先进先出（FIFO）。循环队列判空 front == rear，判满 (rear + 1) % MaxSize == front。
- n 个元素依次进栈，可能的出栈序列个数为卡特兰数 C(2n, n) / (n + 1)。

## 第 4 章 串

- 朴素模式匹配最坏时间复杂度 O(mn)。
- KMP 算法利用 next 数组避免主串指针回溯，时间复杂度 O(m + n)。

## 第 5 章 数组与广义表

- 二维数组按行优先存储时，a[i][j] 的地址 = 基址 + (i × 列数 + j) × 元素大小。
- 对称矩阵、三角矩阵可压缩存储；稀疏矩阵用三元组表或十字链表。

## 第 6 章 树与二叉树

- 二叉树性质：第 i 层最多 2^(i-1) 个结点；深度为 k 的二叉树最多 2^k - 1 个结点；n0 = n2 + 1。
- 遍历：先序、中序、后序（递归或借助栈）；层序遍历借助队列。
- 由先序 + 中序或后序 + 中序可以唯一确定一棵二叉树；先序 + 后序不能。
- 二叉搜索树（BST）：中序遍历得到有序序列；查找、插入平均 O(log n)，最坏退化为 O(n)。
- 删除 BST 结点：叶子直接删；只有一个孩子用孩子替代；有两个孩子用中序后继（或前驱）替代。

## 考前提醒

- 期中考试范围：第 1–6 章。
- 重点题型：复杂度分析、链表指针操作、循环队列判空判满、二叉树遍历序列还原、BST 插入删除。
