# 演示剧本（录视频与彩排用）

负责人：sjy（L）总控；JOHN（F1）操作录屏；有趣（M）配音、剪辑。镜头顺序与 PRD §12.5 一致。

> 全程只使用**演示模式**的虚构数据。画面里不能出现真实姓名、学号、邮件、API Key。

## 1. 录制前准备

| 项目 | 要求 |
|---|---|
| 电脑 | Windows（和安装包一致），分辨率 1920×1080，系统缩放 100% |
| 系统 | 打开「勿扰」，清空通知中心；关掉其他会弹通知的软件；桌面和任务栏干净 |
| 应用 | 安装最新安装包，或在项目里运行 `npm run dev:demo` |
| 模型 | 设置 → 模型：填团队演示用的 DeepSeek Key，点「保存并测试」显示连通。（如果 Shawn 确认本地模型可用，同时配好 Ollama） |
| 时间 | **在 07:30–14:00 之间录**：早安消息只在这个时段发；演示数据里 Lab 5 是「今天 23:59」截止 |
| 重置 | 每次正式录之前：设置 → 开发者 →「重置演示」。它会清空数据、重新加载演示数据、运行一次主动引擎并刷新界面 |

「开发者」页的按钮不要出现在成片里：点按钮时暂停录制，或者剪辑时剪掉。

## 2. 逐个镜头

### 镜头 1（0:00–0:25）痛点

- 画面：浏览器里开着 eLearning、邮箱、iCourse 的**登录页**（不要登录进去，避免出现个人数据）。
- 配音要点：信息分散在好几个平台，靠人工刷总会漏；通用 AI 助理不知道你明天交什么作业。

### 镜头 2（0:25–0:45）首次使用

- 操作：打开引导页（JOHN 完成后），依次展示：选 DeepSeek、复旦账号显示「演示模式」、给助理起名「旦旦」、选说话风格。
- 引导页没做完时的备选：展示「设置 → 模型」和「设置 → 复旦账号」。

### 镜头 3（0:45–1:15）早安与跟进

1. 「重置演示」后，右下角弹出旦旦的系统通知 → 点击。
2. 主对话里的早安消息：今天两节课（08:00 数学分析 III、13:30 数据结构），Lab 5 今晚截止还没交，有邮件等回复。还会有一条「Lab 5 还剩约 N 小时截止」的提醒。
3. 输入：**昨晚写了一半，就差报告了**
   预期：旦旦调用 `get_today` 查到 15:10 之后空闲，建议下午写报告。
4. 输入：**好，4 点提醒我**
   预期：界面显示调用了 `schedule_followup`，旦旦确认会在 4 点提醒。

### 镜头 4（1:15–1:45）动态与引用到对话

1. （暂停录制）设置 → 开发者 →「助教发来 Lab 5 补充邮件」。
2. 恢复录制：对话里出现「关于「Lab 5：链表与栈」：……需要提交一份 PDF 实验报告」，附邮件和作业两张卡片。
3. 切到**动态**页，依次停留：
   - 助教邮件卡片：✓ 已关联到作业「Lab 5：链表与栈」
   - 新作业卡片（大学物理 习题 9 / Lab 6）：✓ 已加入课程目标
   - 交换项目卡片：💡 匹配你的目标：想申请 2027 春季交换
4. 在交换项目卡片上点「引用到对话」，输入：**我适合报吗？如果合适帮我建个目标，排一下准备计划**
   预期：调用 `create_goal`、多次 `add_task`，任务避开周二晚上（记忆里有「周二晚上有社团活动」）。
5. 切到**目标**页，展示「长期目标」里的「交换申请」和带日期的任务。

### 镜头 5（1:45–2:10）建议工单

1. 回到**动态**，在旦旦的建议卡片「要我帮你整理一下申请要求和材料清单吗？」上点「好，帮我做」。
2. 切回对话，可以继续聊别的（展示后台执行不阻塞对话）。
3. 完成后对话里出现「「整理：……」整理好了，放在资源库里了」→ 点资源卡片或切到**资源库**展示清单。

### 镜头 6（2:10–2:30）可验证的闭环

1. （暂停录制）设置 → 开发者 →「在 eLearning 上交掉最近的作业」（交掉的是 Lab 5）。
2. 恢复录制：对话里出现「看到「Lab 5：链表与栈」已经交了 👍 相关提醒都取消了。」
3. 切到**目标**页：「数据结构」进度 +1，Lab 5 已打勾。
- 配音要点：通用助理只能问你「交了吗」，旦旦能直接核实，提醒自动收尾。

### 镜头 7（2:30–2:50）资源库与搜索

1. 把 `demo-assets/数据结构-期中复习讲义.pdf` 拖进对话输入框（会自动存入资源库并引用）。
2. 输入：**根据这份讲义出 10 道复习题，存到资源库**
   预期：调用 `read_resource`、`save_resource`，对话里出现资源卡片。
3. 切到**搜索**（Ctrl+K），输入「复习题」，找到刚才的资源。

### 镜头 8（2:50–3:20）注意力预算与学期节奏

1. 设置 → **主动决策**：展示顶部统计（今天的事件数、打扰次数、放进动态的数量、注意力预算），展开两三条看理由和成本。
2. （暂停录制）设置 → 开发者 →「切换到考试周前」。
3. 恢复录制：对话里旦旦主动问「考试周快到了。要我按各门课的考试时间帮你排一份复习计划吗？」，带「好，帮我做」「先不用」两个按钮。
- 配音要点：平时少打扰，考试周前主动规划；每一次打扰都有理由、有成本。
- 录完这个镜头后，开发者页点「恢复真实校历」。

### 镜头 9（3:20–3:40）记忆透明

1. 设置 →「关于我」：展示旦旦记住的事（周二晚上有社团、想申请交换、对 AI 讲座感兴趣……），删掉一条。
2. 本地模型可用时：设置 → 模型，展示本地模型配置，说明邮件分类、记忆提取在本机完成。

### 镜头 10（3:40–4:30）架构与总结

- 用说明书里的架构图和对比表（PRD §1.5、§7.1）做两三页幻灯片，配音总结四个创新点和路线图。

## 3. 出问题时怎么办

| 情况 | 处理 |
|---|---|
| 模型回复不理想（没调工具、说得太长） | 这一段重录；必要时在「重置演示」后从这个镜头开始录，剪辑时拼接 |
| 模型接口超时或报错 | 检查网络和 Key 余额；准备一个备用 Key |
| 没有弹出系统通知 | 检查是否开着「勿扰」（录制时打开勿扰可能会拦截通知，可以先关掉勿扰录这一段）；或者直接从对话里的早安消息开始拍 |
| 早安消息没出现 | 确认当前时间在 07:30–14:00 之间，然后「重置演示」 |
| 数据乱了 | 「重置演示」，从头再来 |
