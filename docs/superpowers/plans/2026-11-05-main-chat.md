# 主对话交互完善实现计划

目标：按 PRD §5.0–5.1 和 DEVELOPMENT §3.3，把已有主对话从展示骨架补成完整交互：消息卡片能打开、附件能选取/重试并引用、草稿跨页面和重启保留、完整历史可逐页查看、消息快捷操作有明确状态、助理创建的本地结果可安全撤销。保持暖色宋体、单条持续对话、已有真实流式与通知定位。

架构：App 持有对话编辑状态；chat/ 下拆分编辑器、消息列表/消息、引用交互及历史 hook，避免继续堆大 Chat.tsx。历史分页与撤销 SQL 留在 Repo，引用解析放 main/chat/，通过受限 IPC 暴露。资源/目标/动态页只增加可选定位入口，沿用页面现有结构。

边界：校园平台只读；原文仅允许有效 HTTP/HTTPS 链接；无链接的邮件/事项和工单在应用内读取。撤销只限消息真实创建的、仍保持原样的助理目标/任务/成果；学校作业、用户上传和已被后续编辑的内容不允许删除；撤销需用户在界面确认。失败提示保留上下文供重试。不引入新的会话系统、语音、图片理解或副页面重设计。
