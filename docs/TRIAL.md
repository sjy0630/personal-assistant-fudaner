# 试用指南（真实账号）

写给想用自己复旦账号试用 Fudaner 的同学（队员、试用同学）。只想看效果、不登录账号的话，用演示模式即可，见 [README](../README.md)。

> Fudaner 是学生自制的非官方工具。对 eLearning 和邮箱**只读**，不会提交作业、不会发邮件、不会改邮件的已读状态。复旦账号密码只在学校官方登录页里输入，应用不读取也不保存。

## 1. 准备

| 需要 | 说明 |
|---|---|
| 电脑 | Windows 或 macOS |
| Node.js | 22.12 或更高版本（[nodejs.org](https://nodejs.org) 下载 LTS 版） |
| 模型 API Key | 推荐 DeepSeek（[platform.deepseek.com](https://platform.deepseek.com) 注册后创建 Key，充值几元就够试用） |
| 复旦账号 | 能登录 eLearning 的统一身份认证账号 |
| 学生邮箱客户端专用密码 | 可选，接邮箱时需要，见第 4 步 |

## 2. 安装并启动

```bash
git clone https://github.com/sjy0630/personal-assistant-fudaner.git
```

```bash
cd personal-assistant-fudaner
```

```bash

```

```bash

```

已经克隆过的话，先拉最新代码再重新安装依赖：

```bash
git pull origin main
```

```bash
npm install
```

如果启动时报找不到 Electron，执行 `node node_modules/electron/install.js` 后重试；下载慢可以先设置环境变量 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`。

**之前跑过演示模式的**：先到「设置 → 开发者」关掉演示模式，再点「清除所有数据」（演示数据和真实数据存在同一个本地数据库里，不清会混在一起）。

## 3. 首次使用引导

第一次打开会进入 4 步引导：

1. **连接模型**：服务地址 `https://api.deepseek.com`，模型名 `deepseek-chat`，填入 API Key，点「保存并测试连接」。
2. **连接校园**：选「连接我的校园账号」。
3. **认识你**：填昵称、院系、年级。
4. **认识助理**：给助理起名、选说话风格。

## 4. 登录复旦账号、接入邮箱

### 4.1 统一身份认证（eLearning）

1. 「设置 → 复旦账号」点「登录复旦账号」，会弹出一个登录窗口，里面是学校官方的统一身份认证页面。
2. 在这个窗口里**自己**完成登录：输入学号和密码，按页面要求完成验证。
3. **如果页面要求企业微信扫码或确认**：打开手机上的企业微信，按页面提示扫码，或在企业微信收到的登录请求里点「确认」。完成后窗口会自动跳到 eLearning 并关闭。
4. 登录窗口关闭后，设置页里 eLearning 显示「已连接」，点「立即同步」。

> TODO（小鸟游六花）：把真实的企业微信登录步骤和截图补在这里（哪一步出现扫码 / 确认、多久需要重新登录一次）。

登录状态会过期。过期后旦旦会主动提醒，消息里有「重新登录」按钮，点它重复上面的步骤即可。

### 4.2 学生邮箱（可选）

学生邮箱不走统一身份认证，用的是邮件客户端协议（IMAP）：

1. 登录网页版学生邮箱，在设置里开启 IMAP / 客户端协议，生成「客户端专用密码」（具体入口以网页邮箱当前提示为准，可参考[复旦信息化校园指南](https://icampus.fudan.edu.cn/_upload/article/files/74/dd/699f121a4803aa79d828ba217813/3d72ab07-a11d-44df-b61d-61f8c5079b19.pdf)）。
2. 「设置 → 复旦账号 → 学生邮箱」填完整邮箱地址（`学号@m.fudan.edu.cn`）和客户端专用密码，保存。服务器默认 `imap.exmail.qq.com`，端口 `993`。
3. 再点一次「立即同步」，确认能看到最近 14 天的邮件。

## 5. 怎么用

- **主对话**：直接问「这周有什么 DDL」「哪些邮件要回」「帮我排一下今晚的计划」。
- **组作业 / 线下已交的作业**：
  - 在 eLearning 的「待办」里点「标记为完成」，下次同步会自动算完成；
  - 或者直接对旦旦说「Team project 组长已经交了」，它会在应用里标记完成；
  - 也可以在「目标」页勾选对应任务。
- **不用回的邮件**：对旦旦说「这封不用回了」，或在「动态」里那张邮件卡片上点「标记已处理」，它就不再出现在「待回复」里。
- 以上标记**只改应用里的状态**，邮箱和 eLearning 上没有任何变化。
- **动态**：旦旦替你盯着的新作业、公告、课程邮件、和你相关的通知，每张都写了推荐理由。
- **设置 → 主动决策**：看旦旦今天收到了多少事件、打扰了你几次、每次为什么。

## 6. 隐私

- 复旦账号密码只在学校官方登录页输入，应用只保留登录后的会话。
- 邮箱客户端专用密码用系统钥匙串加密保存在本机。
- 所有数据存在本机。使用云端模型时，**默认不会把邮件正文发给云端模型**，只发摘要。需要旦旦读正文时，到「设置 → 模型」勾选授权，或配置本地模型。
- 「设置 → 开发者 → 清除所有数据」可以一键清空。

## 7. 遇到问题

| 现象 | 处理 |
|---|---|
| 同步超时 | 检查网络；校外先连学校 VPN 再试 |
| eLearning 显示需要登录 | 登录过期，重新登录 |
| 邮箱认证失败 | 检查 IMAP 是否开启、客户端专用密码是否正确（不是邮箱登录密码） |
| macOS 保存邮箱密码失败 | 解锁钥匙串后重试 |
| **窗口白屏 / 打不开** | 见下面「白屏怎么办」 |
| 某个作业明明完成了却显示没完成 | 在 eLearning 待办里「标记为完成」后再同步，或直接告诉旦旦；仍不对请反馈 |

### 白屏怎么办

1. **先彻底退出旧的 Fudaner**：关掉窗口后应用还在托盘里运行（Mac 在屏幕右上角菜单栏，Windows 在右下角任务栏），点托盘图标选「退出」。找不到托盘图标的话：Mac 打开「活动监视器」、Windows 打开「任务管理器」，结束名为 Electron / Fudaner 的进程。然后在终端里按 Ctrl+C 停掉 `npm run dev`，再重新运行。
2. 新版本会把界面错误显示在窗口里，并打印到运行 `npm run dev` 的终端（以 `[Fudaner` 开头）。把这些内容复制下来发给开发同学。
3. 窗口里什么都没有的话，按 **Ctrl+Shift+I**（Mac：**Cmd+Option+I**）打开开发者工具，切到 Console，截图红色的报错。
4. 还是打不开，可以先把本地数据挪开再试（**不是删除**，之后还能挪回来）：
   - Mac：把 `~/Library/Application Support/fudaner` 改名为 `fudaner.bak`
   - Windows：把 `%APPDATA%\fudaner` 改名为 `fudaner.bak`

   挪开后能打开，说明是某条本地数据导致的；把第 2、3 步的报错发给开发同学修，修好后可以把文件夹改回原名，恢复原来的数据。
