# 试用指南（真实账号）

写给想用自己复旦账号试用 Fudaner 的同学（队员、试用同学）。只想看效果、不登录账号的话，用演示模式即可，见 [README](../README.md)。

> Fudaner 是学生自制的非官方工具。对 eLearning 和邮箱**只读**，不会提交作业、不会发邮件、不会改邮件的已读状态。复旦账号密码只在学校官方登录页里输入，应用不读取也不保存。

## 1. 准备

| 需要 | 说明 |
|---|---|
| 电脑 | Windows 或 macOS |
| Node.js | 22.12 或更高版本（[nodejs.org](https://nodejs.org) 下载 LTS 版） |
| 模型 API Key | 推荐 DeepSeek（[platform.deepseek.com](https://platform.deepseek.com) 注册后创建 Key，充值几元就够试用） |
| 复旦账号 | 能登录 eLearning 的统一身份认证账号 |
| 学生邮箱客户端专用密码 | 可选，接邮箱时需要，见第 4 步 |

## 2. 安装并启动

```bash
git clone https://github.com/sjy0630/personal-assistant-fudaner.git
```

```bash
cd personal-assistant-fudaner
```

```bash
npm install
```

```bash
npm run dev
```

已经克隆过的话，先拉最新代码再重新安装依赖：

```bash
git pull origin main
```

```bash
npm install
```

如果启动时报找不到 Electron，执行 `node node_modules/electron/install.js` 后重试；下载慢可以先设置环境变量 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`。

### 打包成应用（不想每次 `npm run dev`）

`npm run dev` 每次都要启动开发服务器，比较慢。只是试用、不改代码的话，可以打包成普通应用，之后双击打开：

- **Mac**：

  ```bash
  npm run dist:dir
  ```

  完成后在 `release/mac-arm64/`（Intel 芯片的 Mac 是 `release/mac/`）里找到 `Fudaner.app`，拖进「应用程序」文件夹。想要 dmg 安装包就用 `npm run dist:mac`，dmg 在 `release/` 下。
- **Windows**：`npm run dist`，安装包在 `release/` 下。

注意：

- 应用没有苹果开发者证书。自己电脑上打包的可以直接打开；从别人那里拿到的安装包，第一次要右键 →「打开」，或在「系统设置 → 隐私与安全性」里点「仍要打开」。
- 打包的应用和 `npm run dev` 用**同一份本地数据**（登录状态、同步的数据、设置都通用），但两者不能同时运行：开一个之前先从托盘退出另一个。
- 打包的应用不会随代码更新。`git pull` 拉了新代码后，要重新执行一次打包命令。
- 调试、看报错还是用 `npm run dev`。

**之前跑过演示模式的**：先到「设置 → 开发者」关掉演示模式，再点「清除所有数据」（演示数据和真实数据存在同一个本地数据库里，不清会混在一起）。

## 3. 首次使用引导

第一次打开会进入 4 步引导：

1. **连接模型**：服务地址 `https://api.deepseek.com`，模型名 `deepseek-chat`，填入 API Key，点「保存并测试连接」。
2. **连接校园**：选「连接我的校园账号」。
3. **认识你**：填昵称、院系、年级。
4. **认识助理**：给助理起名、选说话风格。

## 4. 登录复旦账号、接入邮箱

### 4.1 统一身份认证（eLearning）

1. 「设置 → 复旦账号」点「登录复旦账号」，会弹出一个登录窗口，里面是学校官方的统一身份认证页面。
2. 在这个窗口里**自己**完成登录：输入学号和密码，按页面要求完成验证。
3. **如果页面要求企业微信扫码或确认**：打开手机上的企业微信，按页面提示扫码，或在企业微信收到的登录请求里点「确认」。完成后窗口会自动跳到 eLearning 并关闭。
4. 登录窗口关闭后，设置页里 eLearning 显示「已连接」，点「立即同步」。

> TODO（小鸟游六花）：把真实的企业微信登录步骤和截图补在这里（哪一步出现扫码 / 确认、多久需要重新登录一次）。

登录状态会过期。过期后旦旦会主动提醒，消息里有「重新登录」按钮，点它重复上面的步骤即可。

### 4.2 学生邮箱（可选）

学生邮箱不走统一身份认证，用的是邮件客户端协议（IMAP）：

1. 登录网页版学生邮箱，在设置里开启 IMAP / 客户端协议，生成「客户端专用密码」（具体入口以网页邮箱当前提示为准，可参考[复旦信息化校园指南](https://icampus.fudan.edu.cn/_upload/article/files/74/dd/699f121a4803aa79d828ba217813/3d72ab07-a11d-44df-b61d-61f8c5079b19.pdf)）。
2. 「设置 → 复旦账号 → 学生邮箱」填完整邮箱地址（`学号@m.fudan.edu.cn`）和客户端专用密码，保存。服务器默认 `imap.exmail.qq.com`，端口 `993`。
3. 再点一次「立即同步」，确认能看到最近 14 天的邮件。之后新邮件是实时的：邮箱服务器一收到就通知 Fudaner，几秒后同步进来，需要回复的会弹系统通知（应用要开着，关掉窗口在托盘里也行）。

## 5. 怎么用

- **主对话**：直接问「这周有什么 DDL」「哪些邮件要回」「帮我排一下今晚的计划」。
- **它记得多久以前的事**：只有一个主对话，不用新建。最近约 30 条原话每轮都带；更早的会压缩成摘要和「按话题的分段」长期保存，你提到相关的事（「上次说的交换」「我毕业论文选题是什么来着」）时旦旦会自动找回，必要时自己翻聊天记录。长期有用的信息（目标、偏好、固定安排）会单独记下（对话里会提示「📌 已记住 / 已更新」，可以撤销），在「设置 → 关于我」里能看到和删除。想让它按意思而不只是按字词找回，可以在「设置 → 模型 → 语义记忆检索」接一个本机的向量模型（Ollama 运行 `ollama pull bge-m3` 后点「填入 Ollama bge-m3」）。
- **组作业 / 线下已交的作业**：
  - 在 eLearning 的「待办」里点「标记为完成」，下次同步会自动算完成；
  - 或者直接对旦旦说「Team project 组长已经交了」，它会在应用里标记完成；
  - 也可以在「目标」页勾选对应任务。
- **不用回的邮件**：对旦旦说「这封不用回了」，或在「动态」里那张邮件卡片上点「标记已处理」，它就不再出现在「待回复」里。
- 以上标记**只改应用里的状态**，邮箱和 eLearning 上没有任何变化。
- **下载课件**：直接说「帮我下载数据结构第 5 讲的课件」「把线代这周的讲义下下来，帮我总结重点」。文件保存到电脑的「下载/Fudaner/课程名」，PDF、Word、PPT（.pptx）会同时导入资源库，旦旦可以直接读内容、总结、出题。回复下面有「在文件夹中显示」按钮。只读取 eLearning，不会改动任何内容；单个文件最大 200 MB。
- **课表与考试**：登录复旦账号后，到「设置 → 复旦账号 → 课表与考试」点「导入课表」「导入考试安排」，之后每天自动更新。研究生先在「设置 → 关于我」把学历选成硕士或博士。导入后右侧「今天」会按当周实际上的课显示（单双周也算好了），考前 7 天和前一天旦旦会提醒。
- **成绩与绩点**：问「我这学期成绩怎么样」「我的绩点和排名」。成绩只存在本机；默认只有本地模型能看，用 DeepSeek 等云端模型时要在「设置 → 模型」勾选允许发送敏感内容。查排名需要学号（跟旦旦说一次就行，或配置了学生邮箱时自动用邮箱里的学号）。出新成绩时旦旦会告诉你。目前只支持本科成绩。
- **培养方案与选课**：问「我还差多少学分毕业」「专业选修修够了吗」「我下学期选了什么课」。培养方案完成情况和成绩一样按敏感内容处理（云端模型需要授权）；选课结果可以直接查，下学期的选课结果出来后就能看到。目前只支持本科。
- **校园卡与图书馆**：直接问旦旦「卡里还有多少钱」「哪个图书馆人少」，或在「设置 → 复旦账号」里查。余额低于 30 元会提醒充值。
- **学校和院系通知**：不用手动勾选。旦旦按你的院系、学历和兴趣自动关注（教务处、你的院系；想交换就加国际合作与交流处等），想加减直接说「也关注一下经院的通知」「别推保卫处的了」。问旦旦「教务处最近有什么通知」「有没有交换相关的通知」。部分院系网站只允许校园网访问，校外请先连学校 VPN。
- **定时提醒 / 定时任务**：直接对旦旦说「每天 22:00 提醒我背单词」「明早 8 点提醒我交表」「每周一早上 8 点帮我汇总上周的通知、本周 DDL 和考试」。提醒到点弹系统通知；定时任务到点由旦旦自动去做，结果发到对话里（需要配好模型）。在「设置 → 助理 → 定时提醒」里可以查看、暂停、删除或手动添加。应用要开着（关掉窗口后在托盘里也行），电脑睡眠错过超过 12 小时的会跳过。
- **树洞与旦克**：到「设置 → 复旦账号 → 树洞与旦克」用树洞账号（旦挞 App 注册的邮箱和密码）登录一次，之后直接问「数据结构这门课口碑怎么样」「树洞里怎么说哪个食堂好吃」。校园网内直接连接，校外自动走 WebVPN（需要先登录上面的复旦账号）。只读，不会发帖。
- **图书馆文献检索、宿舍电量**：不用任何设置，直接问「帮我在复旦图书馆找图神经网络做分子性质预测的文献」「宿舍还剩多少电」。电量低于 10 度时旦旦会提醒。
- **扩展服务（可选）**：「设置 → 扩展服务」可以接入同学们做的其他复旦 MCP 服务（如 ehall 的体育场馆空闲），需要自己按说明安装。
- **动态**：旦旦替你盯着的新作业、公告、课程邮件、和你相关的通知、校园活动，每张都写了推荐理由。白天每隔 4 小时，旦旦还会按它对你的了解（专业、课程、兴趣、目标、最近聊的事）整理一批：从学校通知和讲座里挑出和你相关的，再联网搜几条你可能感兴趣的资讯（只把检索词发给必应搜索，可以在动态页关掉「联网找资讯」）。也可以随时点「整理一下动态」。需要配好模型。
- **校园活动**：
  - 看到感兴趣的讲座推送，把公众号文章链接直接发给旦旦，它会读出时间、地点、报名方式；说「帮我记上」就加进「目标 → 校园活动」。
  - 问「这周有什么和 AI 有关的讲座」，旦旦会按你的兴趣和空闲时间挑几个推荐。先在「设置 → 关于我」里写上兴趣，或者直接告诉旦旦「我对 xx 感兴趣」。
  - 想自动跟踪某个公众号或学校网站：到「设置 → 通知与活动」添加它的 RSS 地址。公众号本身没有 RSS，可以自己部署 [WeWe RSS](https://github.com/cooderl/wewe-rss) 之类的工具转换（它用你的微信读书账号读取公众号文章，有被限制的风险，请自行判断）。Fudaner 本身不登录微信。
- **设置 → 主动决策**：看旦旦今天收到了多少事件、打扰了你几次、每次为什么。

## 6. 隐私

- 复旦账号密码只在学校官方登录页输入，应用只保留登录后的会话。
- 邮箱客户端专用密码用系统钥匙串加密保存在本机。
- 所有数据存在本机。使用云端模型时，**默认不会把邮件正文发给云端模型**，只发摘要。需要旦旦读正文时，到「设置 → 模型」勾选授权，或配置本地模型。
- 记忆、聊天记录和语义检索用的向量都只存在本机；向量模型的地址不在本机时，只有勾选了「允许隐私任务使用云端」才会用。
- 「设置 → 开发者 → 清除所有数据」可以一键清空。

## 7. 遇到问题

| 现象 | 处理 |
|---|---|
| 同步超时 | 检查网络；校外先连学校 VPN 再试 |
| eLearning 显示需要登录 | 登录过期，重新登录 |
| 邮箱认证失败 | 检查 IMAP 是否开启、客户端专用密码是否正确（不是邮箱登录密码） |
| macOS 保存邮箱密码失败 | 解锁钥匙串后重试 |
| **窗口白屏 / 打不开** | 见下面「白屏怎么办」 |
| 导入课表 / 考试提示需要重新登录 | 在「设置 → 复旦账号」重新登录一次再导入 |
| 某个院系通知显示 ⚠️ | 鼠标停在上面看原因；「只允许校园网访问」时连学校 VPN 后再「保存并读取」 |
| 导入公众号文章提示「需要验证」 | 微信限制了访问频率，过一会儿再试，或把文章正文复制给旦旦 |
| 某个作业明明完成了却显示没完成 | 在 eLearning 待办里「标记为完成」后再同步，或直接告诉旦旦；仍不对请反馈 |

反馈问题时请附上：现象、截图（遮住个人信息）、大致时间。

### 白屏怎么办

1. **先彻底退出旧的 Fudaner**：关掉窗口后应用还在托盘里运行（Mac 在屏幕右上角菜单栏，Windows 在右下角任务栏），点托盘图标选「退出」。找不到托盘图标的话：Mac 打开「活动监视器」、Windows 打开「任务管理器」，结束名为 Electron / Fudaner 的进程。然后在终端里按 Ctrl+C 停掉 `npm run dev`，再重新运行。
2. 新版本会把界面错误显示在窗口里，并打印到运行 `npm run dev` 的终端（以 `[Fudaner` 开头）。把这些内容复制下来发给开发同学。
3. 窗口里什么都没有的话，按 **Ctrl+Shift+I**（Mac：**Cmd+Option+I**）打开开发者工具，切到 Console，截图红色的报错。
4. 还是打不开，可以先把本地数据挪开再试（**不是删除**，之后还能挪回来）：
   - Mac：把 `~/Library/Application Support/fudaner` 改名为 `fudaner.bak`
   - Windows：把 `%APPDATA%\fudaner` 改名为 `fudaner.bak`

   挪开后能打开，说明是某条本地数据导致的；把第 2、3 步的报错发给开发同学修，修好后可以把文件夹改回原名，恢复原来的数据。
